5. TEST 1 — PRESSURE DIFFERENTIAL TEST (ALL DOORS CLOSED)

Procedure: Start the pressurization fan. With all staircase doors in the closed position, measure the pressure differential between the pressurized staircase and the adjacent occupied area / lobby at each level.

Acceptance Criteria: Pressure differential ≥ 50 Pa (staircase relative to occupied area, all doors closed). Where the smoke-stop lobby is also pressurized, staircase pressure shall be higher than lobby pressure. [Ref: SCDF Fire Code Cl. 7.2 / SS 553]

Level Measurement Location Measured ΔP (Pa) Criteria Pass / Fail

6. TEST 2 — DOOR OPENING FORCE TEST

Procedure: With the pressurization system in operation and all doors closed, measure the force required at the door handle to open each staircase door against the air pressure and door closer.

Acceptance Criteria: Door opening force ≤ 110 N measured at the door handle. [Ref: SCDF Fire Code Cl. 7.2 / SS 553]
