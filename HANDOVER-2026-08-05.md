## Gotchas learned the hard way

- Windows PowerShell 5.1 mis-parses UTF-8 scripts without BOM containing non-ASCII;
  keep helper .ps1 files ASCII or save UTF-8 **with BOM**.
- Account API tokens (`cfat_...`) don't pass `/user/tokens/verify`; verify via
  `/accounts` and set CLOUDFLARE_ACCOUNT_ID (account 2a9e346ca1f5901f6ae2d423d2325a6b).
- Cloudflare edge briefly caches 404s for /assets/* after a deploy/restart race —
  a blank page right after switching builds can just be the negative cache (~3 min).
- The service worker (public/sw.js) is fine: navigations network-first, hashed
  assets cache-first. Stale-app problems today were server-side, not SW.
